\begin{center}
{\large\bfseries Análisis de trazas de red con LLMs para mejorar las prestaciones de Sistemas de Detección de Intrusiones (IDSs)}\\[0.3cm]
{\normalsize Detección explicativa de anomalías en tráfico NetFlow mediante LLMs y reglas conductuales}\\
\end{center}
\begin{center}
Mario Soriano Morón\\
\end{center}

%\vspace{0.7cm}
\noindent{\textbf{Palabras clave}: detección de intrusiones, NetFlow, UGR'16, reglas conductuales, explicabilidad, modelos de lenguaje, NotebookLM, LLMs.}\\

\vspace{0.7cm}
\noindent{\textbf{Resumen}}\\

Este Trabajo de Fin de Grado estudia cómo los grandes modelos de lenguaje pueden ayudar a mejorar las prestaciones de un sistema de detección de intrusiones en red, sin convertirse en el motor de detección. El trabajo se apoya en el dataset UGR'16, construido a partir de tráfico real de un proveedor de servicios de Internet (ISP), y analiza sus trazas NetFlow, que resumen cada comunicación mediante metadatos, sin el contenido.

La detección final no la realiza un modelo de lenguaje, sino un clasificador contextual basado en reglas conductuales. Ese clasificador trabaja en tres fases: un análisis local de cada flujo, una agregación global por ventana y una pasada global por origen, para completar la calisificacion de los ataques restantes. Los modelos de lenguaje y NotebookLM intervienen solo como apoyo en la fase de análisis, para interpretar patrones y formular hipótesis que después se comprueban con código y datos.

La evaluación, con precisión, recall y F1, muestra una detección binaria alta, con un F1 de 0,957 en el conjunto principal de estudio, y un buen comportamiento en las familias con patrones más claros, como el escaneo UDP y los escaneos verticales. El escaneo SSH, que con contexto local no se detectaba, pasa a detectarse con un F1 de 0,951 en una semana independiente. El trabajo incluye una comparación con aprendizaje automático clásico como referencia y una aplicación web que ayuda a visualizar, explicar y probar el detector. El enfoque prioriza la explicabilidad: cada decisión se acompaña de la señal que la justifica.

\begin{center}
{\large\bfseries Analysis of Network Traces Using LLMs to Improve the Performance of Intrusion Detection Systems (IDSs)}\\[0.3cm]
{\normalsize Explainable anomaly detection in NetFlow traffic using LLMs and behavioural rules}\\
\end{center}
\begin{center}
Mario Soriano Morón\\
\end{center}

%\vspace{0.7cm}
\noindent{\textbf{Keywords}: intrusion detection, NetFlow, UGR'16, behavioural rules, explainability, language models, NotebookLM.}\\

\vspace{0.7cm}
\noindent{\textbf{Abstract}}\\

This Bachelor's thesis studies how language models can help improve the performance of a network intrusion detection system, without becoming the detection engine itself. The work builds on the UGR'16 dataset, built from real traffic of an Internet Service Provider (ISP), and analyses its NetFlow traces, which summarise each communication through metadata, without the payload.

The final detection is not performed by a language model, but by a contextual classifier based on behavioural rules (version v5). This classifier works in three passes: a local analysis of each flow, a global per-window aggregation and a global per-source pass that recovers SSH scanning. Language models and NotebookLM are used only as support during the analysis phase, to interpret patterns and to formulate hypotheses that are later checked with code and data.

The evaluation, using precision, recall and F1, shows a high binary detection, with an F1 of 0.957 on the main study set, and performs well on the families with clearer patterns, such as UDP scanning and vertical scans. SSH scanning, which could not be detected using local context alone, reaches an F1 score of 0.951 in a separate week. The work also includes a comparison with classical machine learning as a baseline and an interactive web application that helps to visualise, explain and test the detector. The approach prioritises explainability: each decision is accompanied by the signal that justifies it.
