# Pipeline principal

Esta carpeta contiene los scripts principales del flujo de procesamiento de datos.

## Objetivo

Transformar el dataset original en un conjunto de datos limpio y preparado
para su análisis posterior.

## Scripts incluidos

- `clean_large_csv.py`  
  Limpia el dataset original eliminando filas inválidas.

- `count_labels.py`  
  Analiza la distribución de etiquetas del dataset limpio.

- `extract_malicious.py`  
  Extrae únicamente el tráfico malicioso.

## Nota

Estos scripts constituyen el pipeline base del proyecto.
