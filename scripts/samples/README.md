# Generación e inspección de muestras

Esta carpeta contiene scripts para trabajar con muestras pequeñas del dataset.

## Objetivo

Facilitar la inspección inicial de los datos mediante subconjuntos manejables.

## Scripts incluidos

- `sample_1000.py`  
  Extrae una muestra simple de las primeras líneas del dataset.

- `inspect_csv_sample.py`  
  Genera una muestra, muestra una vista previa y permite convertirla a Excel.

## Nota

Estos scripts se utilizaron para comprender la estructura del dataset
y detectar problemas de formato en las fases iniciales del proyecto.
