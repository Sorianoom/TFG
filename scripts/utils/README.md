# Utilidades auxiliares

Esta carpeta contiene herramientas de apoyo utilizadas durante el desarrollo.

## Objetivo

Facilitar tareas puntuales relacionadas con el manejo de datos.

## Scripts incluidos

- `count_lines.py`  
  Cuenta el número total de filas de un archivo CSV.

- `csv_to_excel.py`  
  Convierte un CSV pequeño a Excel para inspección manual.

## Nota

No forman parte del pipeline principal, pero son útiles durante el trabajo con datos.
